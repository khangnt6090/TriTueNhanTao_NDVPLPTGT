# TriTueNhanTao_NDVPLPTGT

## Đề tài

Xây dựng hệ thống nhận diện và phân loại phương tiện giao thông sử dụng trí tuệ nhân tạo.

## Mục tiêu

Xây dựng hệ thống có khả năng nhận diện và phân loại các phương tiện giao thông từ hình ảnh hoặc video bằng mô hình YOLO.

Hệ thống có thể được mở rộng với chức năng theo dõi và đếm phương tiện trong video.

## Công nghệ sử dụng

- Python
- YOLO
- OpenCV
- ByteTrack
- GitHub
- Visual Studio Code
